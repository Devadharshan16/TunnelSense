The IO-VNBD dataset is a goldmine for this specific problem. It contains pairs of CSV files recorded simultaneously:
	  • Smartphone Data (S-*.csv): This contains the noisy, raw sensor data from a smartphone mounted on a car's dashboard (Acceleration X/Y/Z and Gyroscope X/Y/Z). It includes all the engine vibrations and pothole shocks.
	  • Vehicle Ground Truth Data (V-*.csv): This is the "perfect" data recorded by the car's internal
	  computer and high-end GPS. It contains the exact true speed and latitude/longitude of the vehicle.
